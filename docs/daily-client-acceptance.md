# Polished daily-client acceptance record

Status: browser release evidence in progress · October 3, 2026 (America/New_York) · owner [#164](https://github.com/spencerrung/aimtrix/issues/164)

This record joins the roadmap's nine daily-client journeys to reproducible checks. It is an evidence map, not a declaration that every Matrix client, native target, or provider has been accepted. The [capability baseline](capability-baseline.md) describes implementation; the [platform matrix](platform-acceptance.md) retains manual release targets. Synthetic demo content and disposable Matrix accounts are the only data used in these checks.

The Chromium suite runs desktop and Pixel 7 emulation against the built application in CI. Focused Firefox desktop and WebKit desktop/phone jobs cover the browser compatibility set. The all-theme active-conversation, thread and media screenshots are visual evidence for these layouts; Axe checks cover detectable WCAG A/AA issues, not speech output or physical touch behavior. The disposable Synapse/Dex harness and Element Web peer are described in [live Matrix evidence](live-matrix-tests.md), with private, allowlisted numeric diagnostics. An Element Web pass does not imply every listed journey was repeated in Element.

On the October 2 local Linux checkout (Node 26), `npm run check` passed with 1,040 unit tests and the production bundle gate; production-preview Chromium passed 146 tests with 8 intentional skips. Desktop and phone conversation screenshots were inspected, including composer reachability. `npm run test:matrix:privacy` passed 14 tests. The [#219 live CI run](https://github.com/spencerrung/aimtrix/actions/runs/37087566514) passed two clean 45-check Synapse runs, 53 Element Web checks including the QR scan, cache-enabled reload and sustained-sync profiles, and the deliberate diagnostic failure probe. The same revision's Quality workflow passed Firefox and WebKit compatibility, and the desktop-shell workflow passed Linux, macOS and Windows. This checkout has no Docker binary; the live evidence comes from CI's disposable containers.

On October 3, the [#228 live CI run](https://github.com/spencerrung/aimtrix/actions/runs/37126735069) passed the independent two-device encrypted sustained-sync profile: 300/300 exact peer decryptions and Megolm wire sends over ten minutes, bounded timeline rows, 621 ms p95 and 17 MiB retained heap growth. Its standard two-run Synapse, Element Web, cache reload and plaintext sustained-sync jobs also passed. A subsequent local Node 22 acceptance pass added real Chromium microphone-codec and geolocation API paths with Playwright-controlled permissions: `npm run check` passed 1,052 unit tests and the bundle gate; the full Chromium suite passed 154 with 8 intentional skips, including desktop/mobile geolocation API checks with Playwright-controlled permissions and real browser audio-codec checks. Neither synthetic audio nor emulated geolocation establishes physical-device behavior.

The [#231 live CI run](https://github.com/spencerrung/aimtrix/actions/runs/37137462095) passed a disposable 10,000-room cold initial sync on Linux/x64 Chromium 149 and Synapse 1.160.0: server membership readback matched every created room, the fresh client published all 10,000 in 230.3 seconds, kept 100 rows rendered, and opened the last room in 204 ms. Its two clean Matrix runs, Element peer, encrypted and unencrypted ten-minute sync jobs also passed; the matching quality workflow passed browser and bundle gates. This one-host initial-sync observation does not close #163's live account-scale sustained and cross-host budget work.

The [#232 live scale run](https://github.com/spencerrung/aimtrix/actions/runs/37139447810) opened and paged a 350-message room inside a 10,000-room account, then delivered 300 exact new events over ten minutes at 508 ms p95. Its forced-GC retained heap grew 904 MiB during incremental delivery. A [post-fix run](https://github.com/spencerrung/aimtrix/actions/runs/37147925185) repeated the 300 exact events and bounded history with 521 ms p95 while heap stayed between 224 and 229 MiB. The [enforced repeat](https://github.com/spencerrung/aimtrix/actions/runs/37149466220) passed all 10,000 memberships, seven history pages and 300/300 incremental events over ten minutes. Full-room readiness was 229 seconds, deep-room navigation 260 ms, delivery p95 708 ms, and forced-GC heap again stayed at 229/224/224/225 MiB. #163 is closed against its stated budgets; physical-device and cross-host release evidence remains open.

The [#238 live run](https://github.com/spencerrung/aimtrix/actions/runs/37167267241) passed both clean Synapse runs, including encrypted two-account switching and local room/draft isolation, plus the Element peer, browser compatibility and native-shell CI jobs. Before its final test-only changes, the local gate passed 1,082 unit tests and the bundle check, the full Chromium suite passed 158 tests with 8 intentional skips, and the privacy suite passed 18 tests. The final CI jobs passed after those test changes. Different-homeserver identity switching, account removal during a real send, and physical notification routing still need separate evidence.

The [#239 RTC live run](https://github.com/spencerrung/aimtrix/actions/runs/37169623760) passed disposable two-browser encrypted audio, membership writes and capture cleanup in both compatibility and opt-in sticky modes. The modern path issued two JWTs, accepted three visible sticky membership events, and recorded zero encrypted sticky sends. This proves the pinned Synapse/LiveKit/synthetic-authorizer path; deployed authorizers, independent clients, homeserver-mediated tokens and TURN-required NAT remain open. The grouped browser-polish pass on October 3 passed 160 Chromium tests with 8 intentional skips, including desktop/mobile location race checks; desktop and narrow-phone screenshots were inspected. Native account and OAuth tests remain mocked-adapter evidence, not physical-device acceptance.
