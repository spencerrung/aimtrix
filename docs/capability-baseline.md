# Capability and validation baseline

Audit date: **2026-09-11** · Roadmap step [#141](https://github.com/spencerrung/aimtrix/issues/141) · Starting revision: `e25e664`

This inventory reconciles [TODO.md](../TODO.md), the [polish plan](polish-plan.md), implementation, and checked-in tests. It covers the existing release categories and every formerly unchecked compatibility requirement. Source and test references identify evidence to inspect; a test's existence does not mean it passed in this audit. Current command results are recorded separately below. No live Matrix, push-provider, call-provider, or physical-device result is inferred from a closed issue or a demo interaction.

## Reading the evidence

- **Implemented** means the described, bounded behavior has source paths. It does not mean its complete roadmap journey or live interoperability is verified.
- **Partial** means useful behavior exists but a stated part of that capability remains missing or needs a targeted defect reproduction.
- **Absent** means no user-facing implementation or requested validation harness was found in this source review. It does not describe Matrix SDK capability.
- **Source** is inspection; **unit/mock** is a checked-in automated scenario using local data or mocked boundaries; **browser** means an actual browser run of its stated scenarios; **live** means disposable authenticated infrastructure; **native/device** means an actual target runtime or device. Keep these distinct.

The tables' browser column names existing coverage, not fresh passes. The run record determines which coverage ran successfully. All live and native/device boundaries remain **untested by this audit** unless a dated entry below explicitly says otherwise. The 2026-08-22 native spikes documented in [desktop.md](desktop.md) and [mobile.md](mobile.md) are historical build/environment evidence, not current native release acceptance.
