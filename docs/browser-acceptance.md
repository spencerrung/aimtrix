# Browser and accessibility acceptance, September 27, 2026

This pass introduces a deliberate hosted-browser matrix. The full browser suite continues to run on Chromium desktop and Pixel 7 emulation. Focused compatibility journeys run on Firefox desktop, WebKit desktop, and WebKit iPhone emulation in separate Ubuntu CI jobs. Each job preserves screenshots and traces on failure. A skipped phone-only case is reported as a skip, not a pass. These projects test browser engines; WebKit emulation is not a physical Safari or iOS device.

The compatibility journeys cover signed-out labels and Axe checks, a reduced-motion settings dialog with keyboard focus containment and return, long thread composition in Aqua/Graphite/Midnight, a Matrix-link error with Axe, a shared media viewer in all three themes, first-use layout and Axe checks, and phone touch reachability where applicable. The regular Chromium suite retains broader messaging, busy-state, media, error, and modal coverage. The new cross-browser jobs are focused smoke coverage, not an assertion that the entire Chromium suite passes in every engine. Screenshots contain only synthetic demo or fixture content.

Local evidence on the September 27 checkout: Firefox desktop passed the first focused sign-in, modal/reduced-motion, long-thread, and first-use journeys after a sign-in footer contrast fix. The initial Firefox Axe result found 4.32:1 contrast in that footer; the updated color uses the higher-contrast text token. The host is CachyOS/Arch and Playwright's WebKit fallback requires unavailable Ubuntu libraries, so local WebKit launch was blocked before application tests. The Ubuntu CI WebKit job is the browser-engine gate for this change; do not count the failed local launch as an application failure or as a test pass. The final focused and full-suite results belong in the PR validation report.
